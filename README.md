# Piscina Colzi-Martini di via Roma

Aggiornato al **2026-11-23**. A cura di Matteo Tempestini – [github.com/iltempe](https://github.com/iltempe) – mtempestini@gmail.com

## Metodo

- Scopo, budget (EAC e actual), cronoprogramma, rischi e opportunità: solo atti e siti ufficiali.
- Ritardo calcolato solo tra due date ufficiali. Nessuna stima o proiezione.
- Dichiarazioni a voce o di stampa: sezione separata.
- Le somme fatte da noi sono segnalate.
